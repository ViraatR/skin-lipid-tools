How to read this

  • RT off-model: observed RT is >3 robust SD (and >0.2 min) from what this run's own lipids predict for that class/C/DB. Check the peak and MS/MS.
  • Elution order: within a class, more carbons should elute later and more double bonds earlier (reverse phase); Cer should elute before its DHCer. The feature that fits worse is blamed.
  • Isobar fits RT better: another class/adduct with the same m/z (e.g. [M+Na]+ vs [M+H]+, Cer [M+HAc-H]- vs hydroxy-Cer [M-H]-) matches the observed RT; the current annotation does not.
  • BCFA isomer candidate: the same annotation also appears ~0.3-1 carbon-equivalents earlier, the elution signature of monomethyl branched-chain (iso/anteiso) acyl isomers.
  • RT cannot separate co-eluting isobars such as PC x:y vs PE (x+3):y; those need MS/MS head-group fragments.
